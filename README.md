# Haniel Design — Portfólio

## Arquivos do site
- `index.html` — estrutura e conteúdo.
- `style.css` — visual, responsividade e animações.
- `script.js` — menu mobile, efeitos e janelas de apresentação dos projetos.

## Imagens necessárias
Coloque estes cinco arquivos **na mesma pasta do `index.html`** (sem criar pasta de imagens):
- `haniel design.png` — sua foto na seção Sobre.
- `Lumen.png` — identidade visual Lumen.
- `Vyron.png` — identidade visual Vyron.
- `Le Brownie.png` — identidade visual Le Brownie.
- `vans vetor.png` — estudo vetorial da Vans.

Os nomes devem ficar exatamente iguais, inclusive maiúsculas, espaços e extensão. Os quatro projetos aparecem no portfólio e abrem uma janela com descrição do segmento, conceito e direção visual.
